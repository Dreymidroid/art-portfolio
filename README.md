# Ibukunoluwa Shittu — Fine Art Portfolio

An editorial, responsive fine art portfolio website for photographer and visual storyteller **Ibukunoluwa Shittu**.

## Features

- **Editorial Design & Atmosphere**: Signature deep forest canvas palette (`#112419`), warm alabaster typography, and museum-grade presentation.
- **Bespoke Typography**:
  - Headings: `League Spartan`
  - Script Accents: `Caveat`
  - Editorial Narrative: `Plus Jakarta Sans`
- **Exhibition Series**:
  - **Previous Works**: Focal ignition piece with interactive thumbnail switcher.
  - **Unknown Heroes**: Curated museum exhibition wall layout with framed fine-art prints, plus documentary street photography chronicles.
  - **Gele**: Cultural crown portraits celebrating Yoruba headwrap traditions.
  - **Color**: Dual-phase chromatic exploration with azure facial studies and full-length patterned standing figures.
  - **Experience & Education**: Academic background (B.A. Painting, University of Nigeria, Nsukka) and creative practice pillars.
- **High-Resolution Fullscreen Lightbox**: Click any artwork across the site to inspect in full-screen modal with metadata and keyboard support (`Esc` to close).
- **Direct Collaboration CTA**: Quick email copy (`ibukunoluwashittu97@gmail.com`) and commission inquiry form.

## Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React**

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Dreymidroid/art-portfolio.git
cd art-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
